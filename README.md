# Windows 倉頡輸入法更新小工具

幫 Windows 10 / 11 內建的「微軟倉頡」換上更好用的字庫，讓常用繁體字排在更前面、補齊原本打不出來的字。

---

## 事前準備

- 電腦需要連線到網路。
- **只用「倉頡五代」的人**：不用另外裝任何軟體。
- **要用「倉頡三代」的人**：請先下載安裝免費的 [7-Zip](https://www.7-zip.org/)。

---

## 使用步驟（只要 4 步）

1. **下載並解壓縮**本專案（點頁面上方綠色 `Code` → `Download ZIP`，解壓縮到桌面或資料夾）。
2. 對 **`Cangjie-Updater.bat`** 按 **滑鼠右鍵** → 點選 **「以系統管理員身分執行」**（跳出確認視窗請按「是」）。
   - *提醒：直接點兩下會被系統擋住，一定要按右鍵選「以系統管理員身分執行」。*
3. **選擇版本**（不確定怎麼選，直接按 `Enter` 或等 10 秒就會自動選最常用的預設值）：
   - **台灣常用「倉頡五代」**：一路按 `Enter`（或等倒數結束）就會自動幫您裝好「台灣用字優先」版本。
   - **「倉頡三代」使用者**：第一題按 `2`，接著依畫面提示選擇您的 Windows 版本與字集。
4. 畫面顯示「**更新成功**」後，**重新啟動電腦**即完成！

---

## 常見提醒

- **原本的設定會不見嗎？**  
  不會。更新前程式會自動幫您備份舊檔案（放在 `C:\Windows\System32\zh-hk\Backup_...` 資料夾內）。
- **以後 Windows 更新完失效怎麼辦？**  
  Windows 系統更新有時會把倉頡還原成舊版，遇到時再重新執行一次 `Cangjie-Updater.bat` 就好。
