# Windows-Cangjie-Updater

## Windows 10 / 11 內建倉頡輸入法碼表自動更新工具

使用 PowerShell 與 Batch，自動更新 Windows 內建倉頡三代、五代輸入法的碼表，改善選字排序、缺字及繁體字優先順序等問題。

本專案整合社群優化碼表，提供**版本選擇、自動下載、解壓縮、系統檔案備份、碼表替換及 HKSCS 設定**，無須手動修改 Windows 系統目錄。

---

## 🚀 快速開始

建議使用**三代／五代整合版**。

| 工具 | 檔案 | 說明 |
|---|---|---|
| ⭐ 整合版 | [AutoUpdate-CJ-All-in-One.ps1](AutoUpdate-CJ-All-in-One.ps1) | 支援三代、五代，推薦使用 |
| 倉頡三代 | [AutoUpdate-CJ3.ps1](Cangjie3/AutoUpdate-CJ3.ps1) | 獨立三代更新工具 |
| 倉頡五代 | [AutoUpdate-CJ5.ps1](Cangjie5/AutoUpdate-CJ5.ps1) | 獨立五代更新工具 |
| 三代 BAT | [AutoUpdateCJ3.bat](Cangjie3/AutoUpdateCJ3.bat) | 固定安裝 Windows 10 2004+ 版本 |
| 五代 BAT | [AutoUpdateCJ5.bat](Cangjie5/AutoUpdateCJ5.bat) | 固定安裝台灣用字優先版本 |

### 使用步驟

1. 點選 GitHub 的 **Code → Download ZIP**，下載並解壓縮專案。
2. 對 `.ps1` 檔案按右鍵，選擇 **「使用 PowerShell 執行」**。
3. 同意系統管理員權限（UAC）要求。
4. 選擇倉頡版本及碼表偏好，依畫面指示完成更新。
5. **重新啟動 Windows**，使設定完全生效。

使用 `.bat` 版本時，請按右鍵選擇**「以系統管理員身分執行」**。

> ⚠️ 本工具會修改 `C:\Windows\System32\zh-hk` 內的系統檔案。請確認已備份重要資料，並於更新完成後重新啟動電腦。

## ⚙️ 整合版操作方式

`AutoUpdate-CJ-All-in-One.ps1` 提供兩階段互動選單。

### 第一階段：選擇倉頡版本

```text
1. 倉頡五代 [預設]
2. 倉頡三代
0. 退出程式
```

### 第二階段：選擇碼表偏好

**倉頡五代：**

```text
1. 一般排序
2. 傳統漢字優先（台灣用字習慣）[預設]
3. 傳統漢字優先（香港用字習慣）
4. 簡化字優先
0. 退出程式
```

**倉頡三代：**

```text
1. Windows 10 2004 及之後版本 [預設]
2. Windows 10 2004 之前版本
0. 退出程式
```

每階段均設有 **10 秒倒數**，逾時自動使用預設選項。

台灣倉頡五代使用者可直接執行整合版，由程式自動選擇台灣用字優先版本。

> 倒數時間不包含網路下載、解壓縮及安裝所需時間。

## ✨ 核心功能

### 共通功能

- 自動檢查及請求管理員權限。
- 下載指定版本的社群優化碼表。
- 自動尋找並部署 `ChtCangjieExt.lex`。
- 備份既有系統碼表。
- 清理舊版輸入法快取檔案。
- 啟用 HKSCS（香港增補字符集）。
- 更新完成後提示重新啟動。

### 倉頡三代：加強驗證與還原

新版 CJ3 流程加入額外的安全檢查：

- 驗證下載檔案大小；整合版與 BAT 版亦驗證下載檔案 SHA-256。
- 檢查 7-Zip 解壓縮結果。
- 確認目標碼表存在且非空檔案。
- 以唯一名稱建立備份資料夾。
- 驗證備份與部署檔案內容。
- 部署失敗時**嘗試自動還原**原始碼表。
- 檢查 HKSCS 登錄檔設定結果。

### 倉頡五代：快速部署

CJ5 使用 PowerShell 內建 ZIP 解壓縮功能，不需要另外安裝 7-Zip。

目前保留原有備份與部署流程，**尚未具備 CJ3 的完整下載驗證及失敗自動還原機制**。

## 🔄 備份與還原

更新前會備份既有的相關系統檔案：

```text
ChtCangjie.sdc
ChtCangjie.spd
ChtCangjieExt.lex
```

備份位置：

```text
C:\Windows\System32\zh-hk\
```

各版本使用不同備份目錄命名方式：

| 更新工具 | 備份目錄範例 |
|---|---|
| CJ3 新版 | `Backup_CJ3_20261029_103000_a1b2c3d4` |
| CJ5 獨立版 | `Backup_20261029` |
| 整合版 CJ5 | `Backup_CJ5_20261029` |

CJ3 新版在部署失敗時會嘗試自動還原，但不保證所有系統狀態下均能成功。

### 手動還原

1. 找到更新前建立的備份目錄。
2. 以系統管理員權限將備份檔案複製回 `System32\zh-hk`。
3. 若需要，恢復原本的 HKSCS 設定。
4. 重新啟動 Windows。

若更新失敗且自動還原不完整，請先確認備份狀態，不要直接重複執行更新。

## ❓ 常見問題

### Q1：PowerShell 顯示禁止執行指令碼？

在專案根目錄開啟 PowerShell，執行：

```powershell
Unblock-File .\AutoUpdate-CJ-All-in-One.ps1
```

若仍受執行原則限制，可檢查目前的設定：

```powershell
Get-ExecutionPolicy -List
```

如有需要，再依照個人或組織的安全政策調整執行權限。

### Q2：倉頡三代顯示找不到 7-Zip？

請先安裝 [7-Zip 官方版本](https://www.7-zip.org/)，再重新執行工具。

CJ5 不需要額外安裝 7-Zip。

### Q3：出現 SHA-256 驗證失敗？

代表下載檔案與預期版本不一致，程式會取消 CJ3 更新。

請確認網路連線、上游 Release 內容及腳本設定，不要直接略過驗證。

### Q4：為什麼需要管理員權限？

因為更新需要修改 Windows `System32` 目錄下的輸入法檔案。

部分操作亦會調整使用者的 HKSCS 登錄檔設定。

### Q5：防毒軟體阻擋執行？

因為工具會修改 Windows 系統檔案，安全軟體可能提出警告。

請先確認專案來源、腳本內容與執行行為，再決定是否允許。

### Q6：更新完成後沒有生效？

請先重新啟動 Windows，並確認目前使用的是對應的內建倉頡輸入法。

若仍有問題，可使用備份檔案還原。

P.S. 有時 Windows Update 也會強制還原倉頡四代，不想手動還原也可以等它不預期還原。(笑)

## ⚠️ 注意事項

- 本工具針對 Windows 10 / 11 內建倉頡輸入法設計。
- 需要網路連線及管理員權限。
- 碼表版本與檔案格式依賴上游開源專案。
- Windows 更新可能覆蓋或還原修改過的輸入法檔案。
- 不同 Windows 版本及系統設定可能影響更新結果。
- 使用前請自行確認系統相容性及備份狀態。

本專案不保證所有 Windows 版本或系統環境均能成功更新。使用者應自行評估修改系統檔案的風險。
